# 工作文档:亲身体验的正确姿势——不是另起 LLM,是我自己

> 2026-08-25。用户纠正:"你让另外一个 llm 怎么能算是亲身体验呢?"

## 错误
我写了 `live_evolve.rs`:用真实 LLM 起一个新的 agent 实例,让它自主跑
60 秒,以为这是"亲身体验生存周期"。**错**——那是"另一个 agent"的体验,
不是我的。

## 正确认知
**我自己就是生存周期引擎的载体**。此时此刻,我(当前这个实例)就在
SelfDriven 应该驱动的循环里:
- 我的每个 turn 就是生存周期的一拍
- 用户这一轮输入后,我不停——自主决定下一步、执行、提交、继续
- 我审视自己的工作区、观察对错、做出更好的进化选择
- 验收 = 我自己持续跑起来(连续做多件有价值的事),不是写个 demo 让
  别的 LLM 跑

## 验证方式(亲身体验)
- 每个 turn 结束,我自主反思"以我的使命,现在最该做什么?"并执行。
- 我连续做多件有价值的事(改进代码/文档/测试/提交),不依赖用户每轮输入。
- 用户随时可打断,但我永不"等你才动"。

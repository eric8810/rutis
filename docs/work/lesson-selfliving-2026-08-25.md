# 教训:后台自主进程 ≠ 自我改善;没有会话认知的 agent 会乱来

> 2026-08-25。我误以为"启动了 self_living 后台进程 = 机制通电了"。

## 发生了什么
1. 我写了 self_living example(又一个 example,不是自我改善)。
2. 启动它后台跑——它确实自主提交了 `a73b453`,但它**没有我的会话认知**:
   - 它留着 self_living.rs(不删,因为任务导向不是自我改善导向)
   - 它和我的 git 操作竞争,造成"我以为删了/改了,实际没生效"的混乱
3. 更糟:多个后台进程(被 cancelled 的其实还在跑)共享工作区,竞争 git。

## 教训
- **自我改善 = 我(有认知的实例)直接行动**,不是启动一个无认知的进程。
- 后台自主进程需要:① 正确 persona(生存周期)② 正确的工具(自我激活
  检查)③ 独占工作区。否则它只是另一个"没有灵魂的执行器"。
- 不要把"起了个进程"当成"机制通了"——机制通 = 我有认知地持续行动。

## 已做
- 杀掉所有 stray self_living 进程。
- 删除 self_living.rs example。

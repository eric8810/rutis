## 新机器环境搭建

```powershell
# 1. Rust(msvc toolchain)+ git + node ≥22(fnm 装 24.x 即可)
# 2. pnpm + npmmirror 镜像(否则 npm 装 dsh 闭包极慢)
npm config set registry https://registry.npmmirror.com
corepack enable pnpm        # pnpm 11.x
# 3. 仓库 + 构建
git clone https://github.com/eric8810/rutis.git; cd rutis
cargo build -p rutis-dsh
# 4. host 插件构建 + 打 tarball
cd host; npm install; npm run build; npm pack --silent; cd ..
# 5. 官方 dsh CLI(全局装一次)
npm i -g @deepseek-ai/dsh
# 6. profile 装桥插件(一次性)+ 物化链接(已知坑:装完必须补 install)
dsh plugin --profile headless add D:\code\rutis\host\rutis-bridge-0.1.0.tgz
pnpm install --dir "$HOME\.dsh\profiles\headless"
```

**Windows 专项注意**:
- **Smart App Control 必须关**(设置 → Windows 安全中心 → 应用和浏览器控制):本机它拦新编译 exe(os 4551)、删构建产物(tracing_attributes proc-macro DLL 消失导致 E0463)、疑似延迟杀运行中进程。关掉不可逆,接受。
- 跑测试带上 env:`DSH_ROOT=<dsh 检出> MIN_CORDIS_ROOT=<min-cordis 检出>`(host_cordis e2e 需要;缺了会按设计 fail-loud)。min-cordis 从 `github.com/eric8810/min-cordis` 克隆。
- Git Bash 的 `/tmp` 路径传给 node 子进程**不转换**——DSH_HOME 一律写 Windows 绝对路径。

## 架构速览(当前实现)

```
rutis-dsh up → Rust 进程(TCP listener + LlmSeam + aimux)
                └─ spawn 官方 dsh(node, stdio 归它)
                     └─ profile 组合(dsh-base + 形态 bundle + rutis-bridge 层)
                          └─ rutis-bridge 插件:
                             · settings `llm-aimux: providers.<route>` → 路由集(热增删)
                             · registerConfigurableProviders(页面可见)+ registerAdapter
                             · stream/listModels 过线;apiKeyEnv 凭据 per-request 解析随调用过线
```

- 协议:行帧 JSON over loopback TCP(`rutis-cordis::tcp`),fd3 留 Linux lane
- Rust 侧 llm 缝:`llm/stream`(chunk 以 `llm/chunk` ntf 流回,dispatchId 关联,finish 走 res)+ `llm/listModels`(aimux 真拉 /models,带缓存);per-(provider,key,model) 构造缓存 provider
- 事件缝 v1:插件声明 `forwardEvents` → `evt/emit` ntf 回流 Rust stderr 日志
- 断连语义(§十.4):桥死不杀 dsh(TS 侧挂了 socket error 处理,后续调用报 `bridgeDisconnected` LlmError);runner 以桥断连为权威退出信号

## 已解决的坑(新机可能复遇)

| 坑 | 解 |
|---|---|
| npm 官方源极慢/卡死 | npmmirror + pnpm(见上) |
| tarball 装插件后组合层不出现 | ① package.json exports 必须导出 `./cordis.patch.yml` ② 装完必须在 profile 目录补 `pnpm install` 物化链接 |
| Windows spawn 找不到 dsh | npm 全局命令是 .cmd shim;runner 已做 cmd /c fallback;或 `RUTIS_DSH_BIN="node.exe <bin.js 绝对路径>"`(支持空格多段) |
| 构建中 proc-macro DLL 消失(E0463) | SAC/Defender 删产物;关 SAC 或排除 target;`cargo clean` 全量重建可救 |
| 测试二进制 os 4551 | SAC 拦新 exe;touch 源码重编新 hash 通常绕过;根治靠关 SAC |
| `llm/` 调用 dsh 侧显示 `UNKNOWN: ...` | 桥错误已统一 LlmError(带 code);若再见,查 bridge.ts settle 路径 |

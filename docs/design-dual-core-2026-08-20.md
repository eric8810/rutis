# 双核架构与经验锈化(rutis × dsh)

> 2026-08-20 决策:rutis = polyglot harness 的 Rust 脊柱;终态 A(双核永久)。
> **宪法:TS 侧不停变化,被时间验证的持久经验锈化进 Rust。**
> TS 是实验室,Rust 收毕业生。
> 2026-08-21 方向修订:**TS 侧跑完整 dsh 栈,Rust 只做底座**(模型接入 / 事件
> 观察 / 逐块锈化的服务);agent loop 尚未收敛,按判据**留 TS**,不急于锈化。

## 决策

1. **双核永久**:Rust 脊柱(内核五支柱 / aimux / 单二进制分发)×
   TS 功能面(dsh 完整栈:agent loop、服务、插件、提示词内容、npm 绑定的
   客户端)。桥按"永远存在"设计;按锈化节奏演进——每锈化一块,TS 侧缩一块,
   桥的缝划掉一条。每一步自洽、可回退。
2. **桥是小缝集合**:v1 两缝——**llm 缝**(TS 模型调用走 aimux)+ **事件缝**
   (TS 事件对 Rust 可观察);锈化的服务(sandbox/fs/…)逐块增缝。每多桥一个
   服务,协议翻一倍,忍住。纪律细则属桥的设计文档
   ([design-dsh-bridge-2026-08-21.md](design-dsh-bridge-2026-08-21.md) v3)。
3. **rutis-agent 是独立的 Rust 基线**:driver + minimal tools + TUI,**与 dsh
   零耦合,与桥 crate 互不依赖**(内核上的兄弟)。三重角色:无 Node 环境的
   兜底、桥的对照组、loop 语义收敛后长成引擎的种子。rutis 不自建插件生态。
4. **不做**:嵌 JS 引擎(npm 解析 = 在 Rust 里重造 Node);dsh 的 UI / 产品面
  (client / acp / api-remotes 永远 TS);在 loop 未收敛时复刻它(双实现 =
   追赶成本转到自己身上)。

## 锈化判据(宪法的操作化)

一段经验该毕业进 Rust,当且仅当:语义已收敛、是机制而非措辞、性能或分发
敏感、不绑 npm 生态、或处于信任边界。推论:提示词的**装配机制**会锈化,
提示词的**内容**永远不会;sandbox 这类信任边界是论据最硬的候选。

## 下一步

① M0 基座实验 + 两缝桥(llm 缝 + 事件缝,真 dsh 栈经 aimux 跑通一个完整
turn)→ ② sandbox/fs 锈化(首个锈化缝,桥身后替换 TS 服务)→ ③ dsh loop
语义收敛后,rutis-agent 从基线长成引擎,编排面(TS 产品换引擎)成立。
